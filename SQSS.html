Quantum Software Stack (SQS2)

A national, hardware-agnostic software stack that connects quantum processors with high-performance computing and uses AI across the toolchain.

Home / Research / SQS2

About the project

Quantum computers will be used mostly alongside classical supercomputers, as accelerators for targeted problems. Making that practical needs software that can take a program written at a high level, compile it for different kinds of quantum hardware, run it reliably, and coordinate it with HPC resources.

SQS2 develops that software layer for Saudi Arabia. It is designed to work across hardware vendors and qubit technologies, follow open standards, and give national institutions a stack they can operate, extend, and trust.

We are building a national quantum software stack that integrates with HPC and is AI-powered.

The stack

SQS2 is organised in five layers, from the user's program down to the control electronics.

  1. L1

    Applications & SDKs

    Python, C++ and Rust interfaces, with support for common quantum frameworks.

  2. L2

    Quantum programming interface

    Standard APIs for submitting jobs and discovering available devices.

  3. L3

    AI-powered toolchain

    Compilation and circuit optimisation that adapt to the current state of the hardware.

  4. L4

    Platform manager

    A common abstraction over different quantum processors, with scheduling across them.

  5. L5

    Quantum control plane

    Real-time control and measurement for one or several connected quantum processors.

Programs enter at L1 and are lowered layer by layer to pulses at L5.

Focus areas

Hardware-agnostic programming

Open intermediate representations such as OpenQASM 3 and QIR, so the same program can target different devices.

HPC integration

Running hybrid quantum–classical workloads through the schedulers and systems HPC centres already use.

AI across the stack

Machine learning for compilation, calibration, readout and error mitigation.

Distributed quantum control

Coordinating several quantum processors as one resource.

From software to hardware

SQS2 is developed and tested on real laboratory equipment, from the cryogenic systems that host qubits to the electronics that control them.

Why it matters

A sovereign software stack lets Saudi Arabia adopt quantum computing on its own terms, independent of any single vendor. It also builds national expertise in quantum software and supports the goals of Vision 2030 in energy, materials, finance and logistics.
